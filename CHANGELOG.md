# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/), versioning follows [SemVer](https://semver.org/).

## [0.1.0] - Unreleased

First public version.

### Added
- Bottom dock for Hyprland built with Quickshell (QML), one dock per monitor.
- Settings window: corner roundness, size, icon spacing, border style, auto-hide.
- Background opacity slider.
- Border styles: dark (black) and light (white).
- Icons slide smoothly to their new places when the order is changed, and pop in when added.
- Apps (from installed `.desktop` entries or a custom command) and websites (with a chosen browser).
- Hover zoom with spring animation, name tooltips, "running" dot, slide-in/out when hiding.
- `hyprdock` command (`settings`, `toggle`, `stop`, `restart`) and a user-level `install.sh`.
